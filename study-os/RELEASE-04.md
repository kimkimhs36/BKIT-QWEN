# BKIT Study OS v4 — readable, minimal interface

Designed for immediate legibility on iPhone. One primary study action dominates the first screen; relevant deadlines and the next schedule follow. Oversized clock and headings are reduced, explanatory text gains contrast, important controls keep 44+ px tap targets. Status messages and page headings are in Korean. The 24-hour orbit remains accessible in an expandable section. No changes to saved user data, scheduling rules or timer semantics. Automatic unit, typecheck/build, and mobile focus tests must pass before publication.
