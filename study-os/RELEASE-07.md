# BKIT iOS-first 07

- Separates navigation (five tabs) from task creation (top bar action)
  following Apple's published Human Interface Guidelines.
- Retains the genuine Liquid 06 refraction on the floating tab bar.
- Simplifies content surfaces to readable, standard card materials without
  overlay refraction. The new design is calmer and more suitable for study.
- Uses iPhone-safe-area aware bottom sheets, reduced-motion support,
  and 44px+ touch targets.
- Keeps existing state, timers, tasks, local backup and focus mode intact.
- Documents a future native SwiftUI mapping and web-data migration risks.
- Adds both Chromium and WebKit navigation/sheet/material checks.
