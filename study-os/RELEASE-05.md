# BKIT Study OS / Soft Space 05

The visual system changes from neon-green-on-black to a daylight, Apple-inspired (not Apple-branded) pastel UI.

- Neutral deep-ink type with high contrast on soft ivory surfaces.
- Blended pearl, peach and lavender background; translucent, gently blurred floating cards and dock.
- Rounded system sheets, native-accessible select fields, subtle press response and focus rings.
- Coordinated blue/lilac task, review, schedule orbit and timer SVG colors.
- Mobile first; iPad and desktop remain fluid. Honors reduced motion and reduced transparency settings.
- Existing task records, app data schema, logic, timer behavior and storage origin are not modified.
- Automated iPhone-sized computed-style/no-horizontal-overflow check accompanies focus/home tests.
- No Apple logos, product labels or copied Apple assets used.
