08 / 자동 테스트와 실제 생활은 다릅니다

아이폰에서 직접 확인할 단 하나의 흐름

  1. 학교의 실제 공식 공지를 열어 과제와 마감 날짜를 먼저 확인합니다. 확인되지 않은 날짜와 제출 여부는 미확인으로 둡니다.
  2. BKIT에서 원문을 보존한 뒤 사진 포함 전체 ZIP을 만들어 아이폰 파일 앱에 실제 파일이 있는지 확인합니다.
  3. 그 저장된 ZIP을 다시 선택해 읽기 전용 검사에서 공지와 미제출 과제를 대조합니다. 기존 데이터를 확인 중이라면 복원 버튼을 누르지 않습니다.

자동 E2E 통과는 물리 iPhone Safari, 학교 서버 연결, 실제 제출, 7일 성적 개선을 증명하지 않습니다.

이 페이지는 비밀키나 학교 데이터를 전송하지 않습니다. GitHub 공개 API는 사용량 제한·네트워크 문제로 실패할 수 있으며, 그 경우 성공 상태를 꾸며 표시하지 않습니다.
