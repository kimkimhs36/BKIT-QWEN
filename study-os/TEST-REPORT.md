## 발견 후 수정한 문제

- iPad 축소 메뉴의 이름이 CSS 숨김 때문에 접근성 트리에서 사라짐 → 메뉴 버튼·브랜드 링크에 명시적 이름 추가.
- PWA의 자산 캐시가 오프라인 재실행에서 안정적이지 않음 → 버전 있는 빌드 자산 사전 캐시, 서비스 워커 수명에 연결한 저장, 정적 동일 Origin 자산의 Vary 차이에 안전한 조회 적용.
- 작은 메타 텍스트와 집중 카드의 대비 부족 → 중립·세이지 배경에 맞춘 색상 조정, 내비게이션 작은 글자의 opacity 제거.
- 빈 주간 시간표의 가로 스크롤이 키보드로 접근되지 않음 → 이름 있는 focusable 영역 제공.
- 검토 여유 시간이 자정을 넘을 때 내일 계획이 KEEP으로 분류됨 → 실제 요청 날짜와 첫 배치 가능한 시각을 분리하고 회귀 테스트 추가.

## 테스트하지 않은 기능과 한계

- 유료 AI 공급자와의 실제 키·결제·응답 테스트: 없음. ProviderAdapter 출력과 서버 검증은 테스트 더블로 검증했습니다.
- iPhone/iPad Safari 실기기, 홈 화면 실제 설치, iOS 백그라운드 타이머 중단 동작, VoiceOver: 미검증.
- 캘린더 `.ics` 파일 생성 경로는 구현되어 있으나 Apple Calendar에 가져온 뒤 실제 알림 수신은 미검증.
- Web Push, 서버 예약, 로그인·동기화: 미구현이므로 테스트 완료로 주장하지 않습니다.
- 브라우저 완전 종료 후 재기동을 실제 모바일 OS에서 수행하지 않았습니다. 저장 레이어 재생성과 페이지 재로드까지 검증했습니다.
- JSON 저장은 기기 localStorage이며 암호화·자동 원격 백업을 제공하지 않습니다. 현재 다른 탭 변경 감지는 구현했으나 동시 쓰기의 원자적 CAS는 아닙니다.
- 320px 화면에서도 여섯 화면의 가로 넘침을 검사했습니다. 모든 상태의 수동 접근성 평가는 수행하지 않았습니다. axe 통과는 전체 WCAG 준수 인증이 아닙니다.
- 학생의 실제 공부 시작 지연·지각·과제 제출 누락 개선이나 성적 향상은 아직 측정하지 않았습니다.

v1.1 사용 흐름은 `APP_BASE=/`로 만든 실제 배포용 정적 빌드에서도 36개 브라우저 검증을 통과했습니다. 배포 결과는 DEPLOYMENT.md를 확인하세요. 기존 main 병합·DNS 변경은 하지 않았습니다.
