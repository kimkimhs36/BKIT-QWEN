## 실제 완성한 기능

1. **공통 시간 기반 QUESTION RACE**: 현재 문제 경과 시간·목표(1/2/3/4/5/10분)·시간 진행 자동차·결승선·검토 표시·다음 문제 이동. 목표 초과를 실패로 처리하지 않는다. 문제 이동 시 세션 경과 시간에서 배분한 구간을 저장하며 돌아오면 누적된다. 휴식·일시정지 시간은 추가되지 않는다. 완료 여부는 실제 답안 확인 기록으로 표시한다.
2. **4가지 표시**: 기본 숫자(차량 OFF), MINI, DASHBOARD, DRIVE. SVG 눈금·바늘과 경과/남은 시간, 과목·과제, 풀이/미완료/검토 개수. DRIVE의 문제 레이스는 측면 차량·도로·휠·미세한 차체 움직임을 표시한다. 모션 감소·숨김·기기 설정을 따르고 숨겨진 문서에서는 새 학습 애니메이션을 멈춘다.
3. **차고 필수 커스터마이징**: 기존 도장·휠 디자인·배경·스포일러 외에 휠 색상 3종, 서스펜션 높이 3종. 원본 SVG 차체와 휠을 분리하고 공통 차량 모델을 모든 DRIVE·문제 레이스·DRAG RACE에서 사용한다. 외형 변경은 성능을 바꾸지 않는다.
4. **구매·신뢰성**: 비용·잔액 확인 후 명시적 구매 확정, 잠금 안에서 최신 잔액 재검사, 성공/실패 메시지. 기존 Web Locks·저장 성공 후 UI 반영·손상 데이터 보존을 유지한다.
5. **거래 내역·초기 스탬프**: 보상/구매 ID·시각·금액·이유를 같은 차고 저장에 기록한다. UI는 최근 20건과 이전 잔액을 보여준다. 첫 풀이 확인, 일반 학습에서 5분 이상 공부하고 실제 문제 수를 기록해 완료한 스탬프 2종. 기존 일일 상한·동일 이벤트 중복 방지를 유지한다. 규칙은 `economy`와 `catalog`에서 관리한다.
6. **INTERMISSION**: 숲·바다·비 오는 도시·강·초원·밤, TOHEŞAR WINDOW의 오리지널 정적 CSS 일러스트. 실제 사진·영상이라고 표기하지 않는다. 3/5/10분 선택, 같은 마감 안에서 DRAG RACE 이동, 새로고침 후 복구. 원래 문제·자료·초안·스크롤을 유지하고 구체적 복귀 버튼을 표시한다.
7. **WAKE BOMB**: 눌림 피드백 버튼, 기본 30초의 짧은 리셋. CAFFEINE SHOT / ICE RESET / ENGINE START / STORY SHOCK / PHYSICAL RESET을 직접 선택한다. 20/30/40초를 명시적으로 다시 선택할 수 있다. 무음·섬광 없음·카메라 없음. 학습 타이머를 일시정지하고 끝나면 원래 위치로 돌아온다. 자동 재개하지 않는다.
8. **JUGGERNAUT 현황판**: 기존 원장의 오늘 시간·과목 누적·이번 주 공부 시작·풀이 기록·최근 오답 개수, 주간 시간 목표, 3일 내 과제 마감·계획 시간, 최근 자료 복귀. 자료 답안 수와 자료 세션의 문제 수를 중복 합산하지 않는다. 사용자가 확인한 시험 날짜를 입력하며 기본값은 미설정이다. 기존 아카이브와 인트로/건너뛰기를 보존했다.
9. **진입·브랜드**: 기존 간편 타이머의 5분 프리셋 추가. TOHEŞAR는 독립적인 자동차·문화 브랜드로 소개하며 공식 사이트는 차고의 선택형 링크로만 제공한다.

## 부분 구현과 미구현

- JUGGERNAUT: 마감과 계획을 함께 보여주지만 일정 충돌 자동 판정은 아직 없다. 주간 풀이 수는 직접 확인/자기 기록에 근거하며 객관적인 정답률·성적이 아니다. 별도 모의고사 설정·자동 시간 종료·결과표를 갖춘 완전한 실전 시뮬레이터는 미구현이다.
- 보상: 과제 완료·일주일 목표·복습 전용 보상과 추가 스탬프는 미구현이다. 기존 검증된 답안/세션 보상만 지급한다. 5분 스탬프는 현재 일반 문제 수 기록 세션에 한정한다.
- DRAG RACE: 기존 직접 출발·가속·변속·결과의 200m 게임을 보존하고 INTERMISSION 왕복을 추가했다. 거리 선택·장기 결과 아카이브·새 차량 컬렉션은 미구현이다.
- WAKE BOMB: 5개 테마의 안내·카운트다운·복귀를 구현했다. 엔진 점등 연출·오디오·추가 이야기 컬렉션은 없다. 카페인이나 졸음 해소 효과를 주장하지 않는다.
- AWAKE ASSIST: 카메라·MediaPipe·졸음 추정은 **미구현**. 권한 버튼이나 감지 성공을 가장하는 UI도 없다. 기존 화면 Wake Lock은 별도 기능이며 졸음 감지가 아니다.
- THEME ENGINE 2.0: 7개 재질 테마·센서·스프링/물방울 물리·효과 강도/배터리 설정 모델은 **미구현**. PR #19의 기존 라이트/다크 키와 설정 닫기 동작을 그대로 사용한다. 센서·카메라 라이브러리는 추가하지 않았다.
- INTERMISSION 환경음·실제 브랜드 사진/영상·퍼즐/물리 장난감은 없다. 자동 소리·지원되지 않는 백그라운드 알림을 표시하지 않는다.

## 알려진 한계·실제 기기 검수

- iPhone/iPad Safari 실기기·PWA 설치·긴 PDF 필기·화면 잠금·메모리/배터리 검수 필요. 자동 Chromium CSS/터치 테스트는 실제 하드웨어 검수를 대신하지 않는다.
- 센서·카메라·오디오 기능은 이번에 추가하지 않았고 정확도/권한/성능도 검증하지 않았다.
- 휴식이 끝나면 복귀하지만 백그라운드 알림·소리는 보장하지 않는다. 공부 재개는 사용자 버튼으로 한다.
- 표시 모드·원장은 로컬 저장 기반이다. Web Locks 미지원 구형 브라우저의 다중 탭 동시성 한계는 기존과 같다.
- 보상 내역은 최대 60,003건, 보상 ID는 60,000개로 제한된다. 한도 이후 자동 초기화·자산 삭제를 하지 않는다.
- 원래 JUGGERNAUT의 장식 애니메이션 전체에 새 차량 모션 설정을 확장하지는 않았다. 기기 모션 감소와 기존 인트로 건너뛰기를 사용한다.
