## Commercial distribution

MIT, ISC, BSD-3-Clause and Apache-2.0 allow commercial distribution under their respective notice/license conditions; this is not based merely on public source availability. No paid Pro component/template, proprietary media, brand asset, model, sound or external sample content was imported. The only added runtime dependency is pinned `@xyflow/react@12.12.0`; its 20 new lockfile entries and exact license fields are recorded in `dependency-licenses.json`. Full copied notices are served at `/third-party/juggernaut-build02-licenses.txt`, including xyflow/system, d3, classcat, zustand, use-sync-external-store and type packages. D3 is predominantly ISC, d3-ease is BSD-3-Clause; they are not incorrectly labelled all MIT.

## Adoption experiment and boundaries

`spikes/knowledge-map.html` + `.tsx`: React 19 createRoot, two-node/one-edge graph. Real Chromium at 1440×1000 and 390×844: selected `balance`, 2 nodes, 1 edge, no page errors; screenshots `evidence/xyflow-spike-*.png`. This passed before production map was connected to BUILD 01 evidence and `begin('training', false, concept)`.

The production map and scratchpad have browser tests. Tests are emulation/desktop automation, not physical iOS Safari/Apple Pencil/S Pen certification. No claims are made about mobile support for unadopted packages. Unadopted package bundle sizes remain an adoption gate; npm unpacked size is only a screening measure. This avoids adding unused packages to obtain a reassuring but irrelevant build number.
