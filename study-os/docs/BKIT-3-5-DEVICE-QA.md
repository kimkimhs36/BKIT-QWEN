# 실기기 수동 검수 — 배포 전 필수

대상: iPhone Safari, iPad Safari 세로/가로, Galaxy Tab S7 FE 2560×1600+S Pen, desktop. 각 항목에 기기/OS/browser/build SHA, 시작/종료 시각, 성공/실패·스크린샷을 기록한다. 개인 실자료를 넣기 전 검증된 ZIP을 외부에 보관하고, 테스트 데이터나 별도 브라우저 프로필로 수행한다.

1. 홈 원탭 시작, 입력 요구 없음 확인. 2분 뒤 화면 잠금 5분→복귀, wall-clock 경과와 pause 시간 제외 확인. 카운트다운 1분 도달 후 기록이 사라지지 않는지 확인.
2. 시작한 채 PDF 자료 이어풀기, 동일 세션 시간 유지. 답 작성/자가 오답/문제 이동/종료→바로 저장. reload 후 시간·답·오류·이전 문제 위치 확인.
3. 지난 quick 기록 수정, 완료 과제와 사용자 과목 유지. 저장 전 다른 탭 이동 차단 확인. 저장 실패 주입은 개발 프로필에서만 수행.
4. Apple Pencil/S Pen으로 느린 곡선·빠른 획·작은 글씨, 펜을 댄 채 손바닥 놓기. 펜 모드의 한 손가락 스크롤/두 손가락 팬·핀치, 터치 모드 전환. 필압·지연·팜 리젝션은 체감과 가능하면 고속 촬영을 기록. 합성 E2E로 인증하지 않는다.
5. 획 작성 도중 화면 회전, 주소창 접힘/펼침, PDF 확대 상태 회전, 문제/페이지 이동, undo/redo, 다른 화면으로 이동 도중 펜 떼기. 원래 페이지 위치에 획 복구되는지 확인.
6. 사진 촬영과 갤러리 선택, 한글 PDF·큰 이미지 열기, 키보드 표시 중 입력/저장/닫기 버튼과 Safari 하단 UI·홈 인디케이터 간섭 확인. 확대 200%, 가로 iPad에서 공백·버튼 가림 점검.
7. offline 전환 후 앱 재진입, 이미 준비된 PDF/사진 원본·필기 열기. 아직 캐시/로컬 저장 안 된 자료는 실패 안내가 맞는지 확인.
8. ZIP export 중 타이머 실행, 파일을 외부 저장→다시 불러 무결성 검사. 최신 coverage 표시 확인. timer가 있는 상태 restore 비활성/차단 확인. 종료 후 별도 테스트 프로필에서 restore→원본·획·사진·수면·답 확인. 손상 ZIP은 live 데이터를 바꾸지 않아야 함.
9. 두 탭에서 서로 다른 기록 수정. 뒤 탭은 충돌 잠금과 내보내기 가능 상태 확인. 동시에 저장하는 초근접 경합은 아직 완전 잠금 보장이 없음을 기록.
10. 개발 서버에서 build A로 PDF/필기 작성, build B 배포 모의. A 탭이 열린 동안 기다리는 worker 및 옛 lazy chunk가 동작하는지 확인. 저장 확인→모든 BKIT 탭/PWA 창 닫기→재실행, B 적용 및 데이터 복구 확인. 실제 운영 배포 없이 두 버전 fixture로 수행.
11. VoiceOver/TalkBack: 원탭/일시정지/종료/편집 label, countdown 도달 상태. 외부 키보드 Tab/Shift-Tab/Escape로 focus 가림·modal 탈출·돌아올 위치 확인.

자동 검증은 브라우저 엔진·CSS viewport에서의 동작 근거다. 실기기 장시간 절전, OS 강제 종료, Safari eviction, 펜 입력 하드웨어, 카메라 권한을 대신하지 않는다.
