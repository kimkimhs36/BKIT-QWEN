# BKIT Material World 2.0 + Awake Intelligence

기준: 운영 `https://teambkit.com`, 소스 `9777ddc4bcb504b6fc24daea4ab5f38f43c12afa` (`fix/bkit-live-study-start-20261023`). 새 소스 브랜치: `feat/bkit-material-world-awake-20261023`. PR #26, #27은 병합하지 않았습니다.

홈의 DOM 구조·내비게이션·기존 9개 테마 ID를 유지했습니다. 공부 기록·과제·시간표·PDF·GARAGE·AI의 저장 키 및 스키마 변경은 없습니다. Awake 휴식 선택은 기존 `pauseQuick`, `closeSegment`, 답안 저장 guard와 WAKE BOMB을 사용합니다. 자동으로 학습을 재개하지 않습니다.

`material-tokens.css`가 팔레트·표면·버튼·광원·타이포그래피의 단일 정의입니다. 이전 `materials.css`, `premium.css`, `theme-identity.css`, `surreal-liquid.css`, `compact-atmosphere.css`의 반복 팔레트 정의를 제거했습니다. 기존 컴포넌트와 레이아웃 CSS는 유지하고 원래 규칙이 토큰을 소비하도록 수정했습니다.

운영 computed style에서 상단 바의 불투명한 `--mat-bg` 덮어쓰기와 Diamond 시작 카드에 남은 공통 녹색 hero를 확인했습니다. 해당 원본 규칙을 수정했습니다. html/body는 같은 기반 색, root/app-shell/header는 투명한 층, 화면 전체는 하나의 고정 배경을 사용합니다. Safari theme-color와 새로고침 전 초기 색상도 같은 기반 색으로 맞췄습니다. 서비스 워커의 기존 활성화 대기 정책은 유지했습니다.

Diamond는 배경을 결정면으로 나눈 conic/linear gradient, 3개의 각진 장식 면, 카드의 속이 빈 광학 가장자리와 좁은 스펙트럼 대역을 사용합니다. 기울기가 반사각과 광원 위치를 바꿉니다. 텍스트·입력·버튼은 기울기로 이동하지 않습니다. WebKit의 실시간 배경 굴절을 구현했다고 주장하지 않습니다. Diamond는 정밀한 면과 분산광, Glass는 기존 셰이더의 부드러운 광학 변형으로 구별됩니다.

9개 제목은 기존 로컬 Pretendard Variable을 공유하고 웨이트와 자간을 달리합니다. 폰트의 한글 완성형 영역 U+AC00–U+D7A3를 확인했습니다. 한글과 영문에 서로 다른 장식용 폰트를 섞지 않았으며 새 대용량 폰트를 추가하지 않았습니다.

접촉 이벤트는 passive이고, 장식 층은 pointer-events:none입니다. 동시 반응은 4개로 제한합니다. 펜·입력·PDF·문제 풀이 영역은 제외합니다. 기울기에는 중립 보정, 회전 좌표 변환, 이상값 제거, 저역 통과와 감쇠를 적용합니다. 권한 승인만으로 연결 완료를 표시하지 않습니다. 설정에서 미지원/권한/거부/대기/입력 수신/반응/절전/모션 감소/비활성 상태를 구별하고 작은 광원 미리보기를 제공합니다. 입력이 끊기면 대기로 돌아가고 터치로 대체합니다.

## Awake 신호와 제어

기존 MediaPipe Face Landmarker와 로컬 모델/WASM을 재사용합니다. 기본 OFF, 명시적 시작, 카메라 ON/OFF, 일시중지, 종료를 제공합니다. 집중 화면에는 작은 접힌 진입점만 추가했습니다. 미리보기는 기본 숨김이며 카메라 상태는 계속 표시합니다.

- `eyeBlinkLeft/Right`의 양안 일관성, 개인별 열린 눈 기준과 EAR 보조 지표를 함께 사용합니다.
- 약 4초의 보정은 충분한 신뢰 가능한 열린 눈 샘플이 있어야 완료됩니다. 실패하면 관찰 불가를 표시하며 보수적 기본 모드를 직접 선택할 수 있습니다.
- 500ms 미만의 일반 깜빡임은 감김 시간에서 제외합니다. PERCLOS는 최근 60초의 유효 관찰 시간만 사용합니다. 누락·미검출·비정상 타임스탬프·지연 프레임은 감김으로 누적하지 않습니다.
- 2초 이상의 연속 양안 감김은 한 번의 에피소드로 잠그며, 다시 눈을 뜬 상태가 유지되어야 별도 에피소드가 됩니다. 한 번의 긴 감김은 부드러운 안내까지 제공합니다. 반복 에피소드와 충분한 입력 신뢰도가 있을 때 주의 확인·휴식 권장으로 올라갑니다.
- 긴 깜빡임 빈도, 저빈도 샘플에서의 눈 재개방 시간 변화, 고개 하강/복귀를 보조 신호로 사용합니다. 고개 숙임이나 필기 자체는 경고 원인이 아닙니다.
- 임계값은 제품의 보수적인 휴식 안내를 위한 휴리스틱이며 임상 기준이나 사용자 정확도 수치가 아닙니다. 기하학적 입력 품질 점수 역시 확률로 보정된 신뢰도가 아닙니다.
- IDLE, INITIALIZING, CALIBRATING, OBSERVING, FATIGUE_SIGNAL, REPEATED_CLOSURE, REST_RECOMMENDED, UNCERTAIN, PAUSED 상태를 사용합니다. 하강 지연과 안정적인 입력 복귀 구간으로 흔들림을 줄입니다.
- 알림음·진동은 기본 OFF이고 사용자 선택만 반영합니다. 작은 음량의 짧은 음과 70ms 진동 요청만 사용하며 브라우저 지원/거부를 확인합니다. 30초 cooldown과 확인 latch가 반복 알림 폭주를 막습니다. 섬광·강제 밝기·최대 음량은 없습니다.

## 개인정보와 자원 해제

영상, 얼굴 이미지, 랜드마크, 개인별 보정 값이나 신호 이력을 저장하거나 업로드하지 않습니다. 모델 다운로드는 영상 업로드와 별개인 같은 출처 GET입니다. 모든 관찰 상태는 메모리에만 있고 종료 시 지웁니다. 트랙·모델·타이머는 종료·일시중지·패널 닫기·상위 패널 닫기·탭 숨김·페이지 이탈·실패 시 정리합니다. 다시 보인다고 카메라를 자동 재시작하지 않습니다.

실제 네트워크 검사에서 MediaPipe 1.1.1의 기본 사용 로그 POST를 발견했습니다. 공개 opt-out이 없어 고정된 해당 버전의 로거 초기화 한 곳을 Vite 변환 단계에서 제거했습니다 (`localVision.ts`). 추론 코드는 유지합니다. 예상한 upstream 문자열이 바뀌면 빌드는 실패합니다. 개발 의존성 사전 번들도 제외하여 같은 변환을 적용합니다. 출력 번들에서 로거/외부 엔드포인트가 제거되었는지 정적 검사와 실제 모델 네트워크 검사로 확인합니다.

카메라가 켜지면 복잡한 배경 셰이더·장식·블러부터 줄입니다. 추론은 최신 영상 프레임만 처리하며 기본 약 6Hz, 절전 시 약 3Hz에서 추론 소요 시간에 따라 더 낮춥니다. React 표시는 약 2Hz로 제한합니다. 심한 지연·영상 정지 시 관찰 불가, 이어서 카메라 종료로 전환합니다. 발열/배터리를 확인할 수 있는 안내를 제공합니다. 웹에서 실제 기기 온도를 측정한다고 주장하지 않습니다.

## 검증 범위

최종 커밋, 자동 검사 결과, 배포 및 데이터 보존 결과는 [VERIFICATION.md](VERIFICATION.md)에 기록합니다. `before/`는 실제 이전 운영, `verified/`는 브라우저 렌더링, `demo/`는 터치 및 **모의** 기울기 녹화입니다.

WebKit iPhone/iPad 프로필은 실제 iOS 하드웨어가 아닙니다. 실제 iPhone/iPad의 카메라 권한·센서 이벤트·회전·안경·필기·저조도·발열·배터리·진동/오디오·설치 PWA 재실행은 별도 확인이 필요합니다. 생성 영상으로 실제 MediaPipe 모델의 동작과 리소스 해제는 검사하지만 실제 얼굴 감지 정확도의 근거로 삼지 않습니다.
