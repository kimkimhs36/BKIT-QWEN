## 실제 연결한 기능

- **QUESTION RACE / 모의시험**: 기존 세션 시계 하나를 사용한다. 문제별 누적 시간·진입 시각·개별 목표·검토·건너뜀·풀이 메모를 보존한다. 휴식·정지 시간 제외. 실제 등록 자료, 시험 분량·시간 선택, 남은 전체 시험 시간, 종료 시 정확한 구간 마감, 원본 답안/메모 유지, 세션 결과 내 문제별 시간. 과거 답안은 이번 시험의 풀이로 집계하지 않는다.
- **DRIVE**: 좌우 눈금·경과/남은 시간, 중앙 과목·과제·문제 현황, 차량·오늘 실제 시간·쉬어가기 안내. MINI/숫자/계기판/주행이 같은 시계를 사용한다. 공부 자료를 포함한 화면을 넓게 보는 토글, 조용한 모션·목표 도달 표현.
- **TOHEŞAR**: 하나의 오리지널 Touring 36 렌더러. 휠아치·루프·캐빈·램프·도장 반사·휠 비율 개선. 이름, 유광/메탈릭/무광, 휠/색상, 타이어, 차고 조명, 범퍼, 스커트, 데칼, 높이, 스포일러, 배경을 실제로 렌더링한다. 확대·구매 전 부품 미리보기·명시적 구매/취소. 학습·레이스·차고·하루 마무리에서 같은 차량 사용.
- **DRAG RACE**: 200/400m, 출발 신호·반응, 기어·RPM·출력 곡선·질량·그립·항력·변속 손실. 순수 함수가 모든 foreground 시간을 작은 단계로 계산한다. 변속 기록·최고 속도·반응 포함 기록과 거리별 최고 기록을 차고 원장에 저장한다. 휴식 재시작으로 마감 연장 없음. 게임은 공부 시간·크레딧을 지급하지 않는다.
- **보상**: 완료 저장 시각이 있는 실제 과제/수행평가, 직접 답안을 쓴 오답 복습, 주간 목표와 실제 풀이 출력, 첫 공부 시작. 이벤트 ID·일일 100 CR 상한·동일 구매 원장 유지. 스탬프 6종. 소급 보상·수면 축소 보상·현금 기능 없음.
- **휴식**: 6개 자연 공간과 TOHEŞAR WINDOW에 느린 장면별 모션. 직접 만든 합성 환경음 4종을 명시적 버튼으로 재생하며 현장 녹음이라고 표시하지 않는다. 화면 전환·숨김에서 소리 정리. WAKE BOMB의 5개 시각 모드, 눌림 버튼·중지·이야기 선택. 원래 문제·답안·스크롤·정지된 타이머 복귀.
- **테마**: Classic Light / Forest Dark / Liquid Glass / Peach Flow / Diamond / Champagne Gold / Soft Jelly / Living Droplets / Night Sprint. 적용 전 카드·버튼·입력·내비게이션·계기판 예시. 재질·곡률·그림자·반사·배경·눌림 차이. 기존 라이트/다크 키를 기준으로 새 재질 키를 호환한다. 모션 OFF/감소·강도·절약·비활성 탭·집중 중 정적 표현·지연 감지. 장식만 움직이는 선택형 기울기 반응과 터치 대체. 고급 엔진은 초기 precache에서 제외.
- **AWAKE ASSIST 실험**: 기본 OFF. 허용 후에만 동일 출처의 MediaPipe CPU/WASM 모델을 읽고 기기 내 4Hz 분석. 얼굴·눈 신호·큰 자세 변화의 불확실성, 지속/반복 신호에 휴식 제안. 얼굴 부재를 수면으로 판단하지 않는다. 영상·특징 저장/업로드 없음. 즉시 종료·탭 숨김 종료·느린 분석 자동 종료. 합성 카메라로 초기화/분석/종료와 외부 요청·업로드 0건을 확인했다. 실제 사람의 졸음 정확도를 검증한 기능이 아니다.
- **하루 경험 / JUGGERNAUT**: 작은 공부 시작 경로 유지, 하루 마무리 요약, 확인한 시험 날짜·과목 목표·범위·남은 복습·주간 행동·준비 체크, 실제 시간 겹침. 계획/테마/차량/시험은 ZIP 보관에 포함하며 시험 계획 병합은 로컬 기존 과목을 보존한다.
