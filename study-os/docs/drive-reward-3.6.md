# BKIT 3.6 — DRIVE & REWARD

개발 브랜치: `feat/bkit-3-6-drive-reward-20261019`. 운영 배포 없음.

## 출발점과 사용법

2026-10-19 확인 시 운영 `main`은 빌드 산출물 커밋 `44a0ef3`이다. 소스 통합 PR #18은 `integrate/bkit-3-5-school-ready-20261019`, 다크모드 PR #19는 그 위의 `fix/bkit-3-5-dark-mode-settings-toggle-20261020` (`5769c66`)이다. 본 작업은 #19에서 분기했으며 기존 PR과 운영 브랜치를 수정하지 않았다. #19의 컴파일·6개 테마 브라우저 검사는 성공, 전체 회귀는 작업 시작 시 진행 중이었다.

- 오늘 또는 집중 화면의 **DRIVE MODE**로 전환한다. 기본 타이머로 언제든 돌아갈 수 있다.
- 스톱워치와 카운트다운은 기존 버튼으로 시작·일시정지·종료한다. 과제나 자료에 연결한 시간도 그대로 유지한다.
- 자료 학습에서는 전체 집중/모의고사 목표 시간과 현재 문제 주변 최대 5개의 작은 자동차를 표시한다. 문제 이동은 기존 문제 목록을 사용한다.
- **더보기 → TOHEŞAR GARAGE**에서 무료 차체 색상·배경을 바꾸고, 학습 크레딧으로 휠·스포일러·튜닝을 확정 구매한다. 보유 파츠는 선택 메뉴에서 장착한다.
- 타이머 또는 차고의 **DRAG RACE · 3분 쉬기**을 누르면 답안을 먼저 저장하고 타이머를 일시정지한다. 3초 출발 신호, 가속 버튼을 누른 채 기어 변속, 200m 결과 화면으로 이어진다. 키보드는 Space 가속/출발, ↑ 변속, Escape 복귀를 지원한다.
- 3분이 끝나면 원래 화면·문제·초안·스크롤 위치로 복귀한다. 공부를 재개할 때 이어하기를 직접 누른다. 다시 달리기나 새로고침은 휴식 마감을 연장하지 않는다.

## 데이터 보존과 모듈 경계

`quickTimer.ts`, `session.ts`, 학습 모델, API 서버, 사진·첨부파일·필기 저장 엔진은 변경하지 않는다. DRIVE는 기존 엔진의 경과 시간과 목표만 읽고 표시한다. 타이머 종료와 답안 저장은 기존 경로를 사용한다.

`src/drive/`에 자체 제작 SVG 차량, 별도 차량 스키마/보상 순수 함수, DRIVE 화면, 레이스 물리와 UI를 둔다. 차고와 레이스 화면은 지연 로딩한다. 레이스에 학습 상태나 저장 콜백을 전달하지 않는다. 게임 오류 경계와 호스트의 독립적인 휴식 마감 검사가 복귀 버튼을 유지한다. 휴식은 포털로 열어 기존 학습 컴포넌트와 필기 화면을 마운트한 채 유지한다.

| 저장 항목                              | 용도                                    | 보존 방식                                                               |
| -------------------------------------- | --------------------------------------- | ----------------------------------------------------------------------- |
| 기존 `bkit.study-os.v1` 및 IndexedDB   | 학습·과제·답안·첨부·필기                | 기존 스키마·충돌 보호·저장 경로 유지                                    |
| `bkit.drive-garage.v1` (localStorage)  | 차량·화면 설정·보유 파츠·보상 중복 방지 | 버전 1 검증, 쓰기 성공 후 UI 반영, Web Locks로 탭 사이 구매/보상 직렬화 |
| `bkit.drive-break.v1` (sessionStorage) | 휴식 절대 마감·복귀 화면·스크롤         | 동일 탭 새로고침 시 복구, 만료 시 복귀, 저장 불가 시 메모리 마감 사용   |

차고가 손상되면 원문을 덮어쓰지 않고 변경을 잠근다. ZIP 백업에는 차고의 원문도 포함해 학습 데이터 구출을 막지 않는다. 이전 ZIP에 차고 항목이 없으면 현재 차량을 유지한다. 기존 백업 검증·복원 저널·사진 충돌 해소·복구 롤백 규칙을 유지한다. 원래 학습 JSON/API 전용 백업은 기존 범위를 유지하고 차량은 전체 ZIP에서 보존한다.

Web Locks를 지원하지 않는 구형 브라우저에서는 매번 최신 저장값을 읽는 동기 저장을 사용한다. 다중 탭 동시 구매 직렬화 검증 대상은 Web Locks를 제공하는 최신 Safari/WebKit·Chromium이다.

## 보상 규칙

- 설치 이후 직접 답안을 제출하고 스스로 확인한 자료 문제: 문제 ID마다 한 번 5 CR. 정답과 오답의 보상이 같아 오답 기록을 숨기도록 유도하지 않는다.
- 일반 집중 문제의 직접 확인: 집중 세션 ID마다 한 번 5 CR. 종료 시 중복 지급하지 않는다.
- 자료·답안 학습이 없는 일반 세션: 60초 이상 공부하고 실제 문제 수를 1개 이상 기록해 종료하면 한 번 10 CR.
- 하루 최대 100 CR (UTC 기준). 한도를 넘긴 완료 이벤트도 처리해 다음 날 몰아서 청구할 수 없다.
- 타이머 경과, 앱 방치, 단순 종료, 레이스, 재시도 반복은 크레딧을 늘리지 않는다. 기존 기록의 일괄 소급 지급도 없다.
- AERO 휠 15 CR, TOURING 스포일러 10 CR, SPRINT 튜닝 20 CR. SPRINT는 가속 +12%; 외형 파츠는 성능을 바꾸지 않는다.
- 실제 결제, 암호화폐, 교환·송금, 확률형 뽑기, 광고·외부 보상 API가 없다. 차량·게임 모듈은 네트워크 요청을 하지 않는다.

## 모바일·모션·성능

최대 30Hz 게임 처리, 대기·결과는 4Hz, 모션 감소에서는 움직임 없이 10Hz 수치 표시를 사용한다. 물리는 최대 50ms 단위로 나눠 모션 설정이 성능 차이를 만들지 않게 한다. 1초 이상 중단되거나 백그라운드로 이동한 주행은 안전하게 종료한다. 가속은 pointerup/cancel/lostcapture·blur에서 해제한다. 닫을 때 타이머·키보드·visibility·미디어 쿼리 이벤트를 정리한다.

차량은 원본 SVG 한 종류를 공유한다. WebGL, 외부 이미지, 고해상도 캔버스, 물리 라이브러리를 쓰지 않는다. 큰 자료에서는 문제 자동차 렌더링을 최대 5개로 제한하고 결과 집합을 재사용한다. 기기의 `prefers-reduced-motion`, 별도 모션 감소·애니메이션 숨기기를 지원한다. 모션 감소에서는 자동차 이동과 휠 회전을 끈다. 조작은 44px 이상이며 강한 섬광·소리·진동·카메라·센서 권한 요청이 없다.

## 확장 설계 — 런타임 미구현

핵심 A/B/C 구현을 우선했다. 다음 기능은 아래 경계를 재사용하며 현재 자동 활성화하지 않는다.

| 확장              | 연결 경계                                                                       | 구현 시 조건                                                                                                                             |
| ----------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| INTERMISSION 공간 | 현재 호스트의 휴식 마감·복귀 위치, `onReturn`을 공유하는 선택형 활동 레지스트리 | 모든 활동이 같은 절대 마감 사용, 학습 저장 접근 금지, 활동 교체로 시간 연장 금지                                                         |
| WAKE BOMB         | 선택형 휴식 활동, 화면 안내·가벼운 카운트다운                                   | 사용자가 시작, 즉시 종료 가능, 섬광·강제 놀람·큰 소리 없음, 숨은 타이머 없음                                                             |
| 젤리·유리 테마    | 공유 차량/테마 선택 → 별도 렌더러에 기울기 입력                                 | iOS 권한은 명시적 탭에서만 요청, 거절 시 정적 테마, 각도 clamp·저역 필터·30Hz 제한, 숨김/종료 시 센서 구독 해제, 모션 감소면 센서 비활성 |
| 수능 JUGGERNAUT   | 기존 자료·문제 ID를 가진 학습 진입점 + 차량 설정 읽기                           | 기존 원본·필기·답안 저장 경로 사용, 타이머 복제 금지, 보상은 기존 완료 증거만 재사용                                                     |

향후 활동 계약은 읽기 전용 차량 설정, 절대 `deadline`, `onExit`만 전달한다. 카메라 감시나 개인정보 전송은 이 계약에 포함하지 않는다. 휴식 마감·데이터 보존·권한 거절·모션 감소 테스트를 통과한 확장만 추가한다.

## 검증과 배포 경계

`npm run dev`로 실행한다. `npm run build`, `npm test`, `npx playwright test tests/e2e/drive-reward.spec.ts --project=desktop --project=webkit-iphone --project=webkit-ipad`로 핵심 기능을 재현한다. 기존 `quick-timer`, `dark-mode-settings`, `learning-engine`, `digital-paper`, `storage-readiness`, `school-ready`, `assessment-readiness`도 회귀 대상으로 유지한다.

CI는 `.github/workflows/verify-bkit-3-6.yml`이며 읽기 권한으로 빌드·전체 단위 테스트·3개 브라우저 회귀만 실행한다. 배포 job이나 main/release 푸시가 없다. PR은 #19 소스 브랜치를 기준으로 검토한다. #19/통합 브랜치가 변경되면 그 차이를 별도로 확인한 뒤 재통합한다. 운영 배포는 사용자 승인 이후의 별도 작업이다.

Playwright WebKit의 iPhone/iPad 프로필은 Safari 엔진 및 CSS/터치 환경 검증이다. 실제 iPhone/iPad 하드웨어의 장시간 성능, 홈 화면 설치 앱, 오디오·센서 동작은 이 환경에서 실측하지 않았다.
